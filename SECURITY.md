## Reporting a Vulnerability

Reporte de Vulnerabilidades (Español)
Si encuentras una vulnerabilidad en Sycamore, por favor repórtala siguiendo estos pasos:

📩 Dónde reportar: Envía un correo electrónico a ghdipaolo@gmail.com o abre un issue privado en GitHub utilizando la opción Security Advisory.

⏱️ Tiempo de respuesta: El equipo revisará tu reporte en un plazo de 72 horas y te mantendrá informado sobre el estado de la investigación.

✅ Proceso de aceptación:

Si la vulnerabilidad es confirmada, se trabajará en una solución y se publicará una actualización de seguridad en la próxima versión estable.

Si el reporte es rechazado, se explicarán las razones y se ofrecerán recomendaciones alternativas.

🤝 Expectativas:

Se agradece la colaboración responsable, evitando la divulgación pública de la vulnerabilidad hasta que se publique el parche.

Reconoceremos tu aporte en las notas de la versión, salvo que prefieras mantener el anonimato.

Vulnerability Reporting (English)
If you discover a vulnerability in Sycamore, please report it by following these steps:

📩 Where to report: Send an email to ghdipaolo@gmail.com or open a private issue in GitHub using the Security Advisory option.

⏱️ Response time: Reports will be reviewed within 72 hours, and you will be kept informed about the investigation status.

✅ Acceptance process:

If the vulnerability is confirmed, a fix will be developed and released in the next stable update.

If the report is declined, reasons will be provided along with alternative recommendations.

🤝 Expectations:

Responsible disclosure is appreciated; please avoid public disclosure until a patch is released.

Your contribution will be acknowledged in the release notes unless you prefer to remain anonymous.
