# Contribuciones

Gracias por contribuir al repositorio de Sycamore.

## Licencia de contribuciones

Al enviar una contribución, aceptas que tu aporte será licenciado bajo las condiciones de este repositorio:

- Código fuente y artefactos ejecutables: Apache License 2.0.
- Documentación, diseños, textos, imágenes y materiales no ejecutables: CC BY 4.0.
- Datos: CC0 por defecto, salvo indicación específica en la carpeta correspondiente.

## Certificado de origen (DCO)

Este proyecto usa DCO por defecto. Antes de enviar un pull request, puedes firmar cada commit con:

```bash
git commit -s -m "Mensaje del commit"
```

Esto añadirá automáticamente la línea:

```text
Signed-off-by: Tu Nombre <tu-email@ejemplo.com>
```

## Requisitos para contribuciones

- Asegúrate de tener derecho a enviar el contenido.
- No publiques material de terceros sin permiso o licencia compatible.
- Incluye pruebas, documentación o evidencia cuando corresponda.
- Usa nombres, comentarios y mensajes de commit claros y trazables.

## Proceso sugerido

1. Haz un fork del repositorio.
2. Crea una rama para tu cambio.
3. Realiza la contribución y documenta el impacto.
4. Abre un pull request con una descripción clara y enlaces relevantes.

## CLA formal

Si tu organización requiere un acuerdo formal de contribución (CLA), contacta con el mantenedor antes de enviar cambios.
